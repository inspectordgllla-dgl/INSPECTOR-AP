# நூலக பணி - உத்தேச மாத பயணத் திட்டம் (Library Tour Planner)

Flask வலை பயன்பாடு. Google Sheet-ல் உள்ள நூலகங்கள் பட்டியல் மற்றும் அரசு விடுமுறை
நாட்கள் தரவைப் பயன்படுத்தி, ஒவ்வொரு மாதத்திற்குமான உத்தேச பயணத் திட்டத்தை
(Date / Day / Place of duty) ஒரு நாள் வாரியாக பதிவு செய்யத் தருகிறது. பயணத் திட்டம்
PostgreSQL database-ல் தானாக சேமிக்கப்படும், மேலும் அதிகாரப்பூர்வ அனுமதி கடிதத்தையும்
(PDF) உருவாக்கலாம்.

## புதிதாக சேர்க்கப்பட்டவை

- முதன்மைப் பக்கத்தில் 3 dashboard பட்டன்கள்: உத்தேசப் பயணத் திட்டம் / உண்மைப் பயணத்
  திட்டம் (விரைவில்) / ஆய்வு-பார்வை அறிக்கைகள் (விரைவில்)
- "நூலகங்கள் பார்வை" தேர்வு செய்தால் நூலகம் dropdown காட்டப்படாது.
  "நூலகங்கள் ஆய்வு" தேர்வு செய்தால் நூலகம் பெயர் + ஆய்வு ஆண்டு கட்டாயம்.
- ஒரு நாள் பதிவு செய்தவுடன் அடுத்த நாள் தானாகத் திறக்கும் (முழு மாத அட்டவணையும்
  ஒரே நேரத்தில் காட்டப்படாது).
- அரசு விடுமுறை நாட்கள் (HOLIDAYS sheet) தானாக "அரசு விடுமுறை" எனப் பதிவாகும் —
  work-type தேர்வு தேவையில்லை. வெள்ளிக்கிழமை தானாக "வார விடுமுறை" (edit முடியாது).
  மாதத்தின் 2-வது சனிக்கிழமை தானாக "இரண்டாம் சனிக்கிழமை அரசு விடுமுறை". மற்ற சனி/
  ஞாயிறு சாதாரண வேலை நாட்கள்.
- பயணத் திட்டம் ஒவ்வொரு நாள் பதிவும் PostgreSQL database-ல் உடனடியாகச் சேமிக்கப்படும்.
- மாதம் முழுமையானதும் "உத்தேச பயணத்திட்ட அனுமதி கடிதம்" பட்டன் தோன்றும் — legal
  size, portrait PDF கடிதம் (இணைத்திருந்த மாதிரி கடிதம் போன்ற வடிவமைப்பில்) —
  ப.வெ.எண் மற்றும் நாள் மட்டும் நீங்கள் தட்டச்சு செய்யும் இடம்.

கடிதத்தில் நிரந்தரமாகத் தோன்றும் பெயர்/பதவி விவரங்கள் `app.py`-ன் தொடக்கத்தில்
`LETTER_SENDER_NAME`, `LETTER_SENDER_DESIGNATION` போன்ற மாறிகளில் உள்ளன —
தேவைப்பட்டால் அங்கே மாற்றிக்கொள்ளலாம் (அல்லது Render-ல் Environment Variable ஆக
அமைக்கலாம்).

## 2. உள்ளூரில் இயக்குதல் (Local run)

```bash
pip install -r requirements.txt
python app.py
```

DATABASE_URL environment variable அமைக்கவில்லை என்றால், உள்ளூரில் ஒரு
`tour_planner.db` (SQLite) கோப்பு தானாக உருவாக்கப்பட்டு பயன்படுத்தப்படும் — Render-ல்
deploy செய்தபின் PostgreSQL தானாகப் பயன்படுத்தப்படும்.

பிறகு browser-ல் `http://localhost:5000` திற்க்கவும்.

## 3. GitHub-ல் பதிவேற்றுதல்

```bash

git branch -M main
git remote add origin https://github.com/<உங்கள்-username>/library-tour-planner.git

```

## 4. Render-ல் Deploy செய்தல்

1. https://render.com -ல் உள்நுழையவும் (GitHub கணக்கு மூலம் உள்நுழையலாம்).
2. **New +** → **Blueprint** என தேர்ந்தெடுக்கவும் (render.yaml-ல் database-ம்
   சேர்க்கப்பட்டிருப்பதால், "Web Service" அல்ல, "Blueprint" வழியாகச் செய்ய வேண்டும்,
   இதனால் PostgreSQL database-ம் தானாக உருவாகும்).
3. நீங்கள் push செய்த GitHub repository-ஐ இணைக்கவும்.
4. "Apply render.yaml" தேர்ந்தெடுக்கவும் — இது web service மற்றும் ஒரு free
   PostgreSQL database இரண்டையும் உருவாக்கி, `DATABASE_URL`-ஐ தானாக இணைக்கும்.
5. **Apply** அழுத்தவும். சில நிமிடங்களில் இணையதளம் தயாராகிவிடும்.

## 5. பயன்பாடு

- முதன்மைப் பக்கத்தில் "உத்தேசப் பயணத் திட்டம்" பட்டனை அழுத்தவும், ஆண்டு/மாதம்
  தேர்ந்தெடுக்கவும்.
- அரசு விடுமுறை, வார விடுமுறை (வெள்ளி), 2-வது சனி ஆகியவை தானாகப் பதிவாகும்.
- ஒவ்வொரு வேலை நாளுக்கும் "பணியிடம்" தேர்ந்தெடுக்கவும். "நூலகங்கள் ஆய்வு"
  தேர்ந்தெடுத்தால் நூலகம் பெயர் மற்றும் ஆய்வு ஆண்டு கட்டாயம். பதிவு செய்தவுடன்
  அடுத்த நாள் தானாகத் திறக்கும் — ஒவ்வொரு பதிவும் உடனடியாகச் சேமிக்கப்படும்.
- மாதம் முழுமையானதும், "உத்தேச பயணத்திட்ட அனுமதி கடிதம்" பட்டனை அழுத்தி, ப.வெ.எண்
  மற்றும் நாளைத் தட்டச்சு செய்து PDF கடிதத்தைப் பதிவிறக்கம் செய்யலாம்.

## 6. அடுத்த கட்டம் (பின்னர் சேர்க்கலாம்)

- "உண்மைப் பயணத் திட்டம்" மற்றும் "ஆய்வு / பார்வை அறிக்கைகள்" பிரிவுகளுக்கான
  முழு செயல்பாடு.
- முந்தைய மாதங்களின் பயணத் திட்டங்களை திருத்தும் வசதி.
